# M13 export: engine import checklist

**Status: Godot and Unreal checked (2026-10-04, headless imports on the reference laptop); Unity not
yet.** **Priority: Godot and Unreal** (the owner's targets); Unity is a nice-to-have, check it last. What *is* verified (CPU, Linux, Blender 5.2.2 + gltfpack 0.25): the files exist,
the FBX carries the LOD group / `UCX_` names, the Godot GLB the `-convcolonly` node, LODs shrink and keep
UVs, the hull is convex and encloses the mesh, print files are millimetres with Z up
(`tests/test_export_profiles.py`, `tests/test_blender_ops.py::test_engine_profiles`).

## Procedure

1. Pick one finished asset (e.g. a `game-prop` bench output, `docs/bench/phase0.md`) with a known
   height from its `validate` checklist. Note the asset id, version and height here.
2. Export each profile from that version (UI, or MCP `export(asset_id, version, profile)`):
   `unity`, `unreal`, `godot` (defaults: `lods` and `collision` on). Files land in
   `library/<asset>/<NNN>_export/<profile>/`.
3. Import into each engine as below, tick the boxes, fill the results table, commit this file.

`<name>` = the asset id. Expected LOD triangle counts: ≈ 100 / 50 / 25 / 10 % of LOD0.

### Unity (6.x): `unity/<name>.fbx`

Drag the FBX into `Assets/`. Model tab: defaults (Convert Units on).
- [ ] Scale: the model is as tall as the asset's height in units (1 unit = 1 m; compare with a default
      Cube), Transform scale 1 1 1.
- [ ] Up axis: upright (Y up), rotation 0 0 0 on the instance.
- [ ] LODs: the instance has an **LOD Group** with LOD0..LOD3 (`<name>_LOD0..3`), triangle counts as above.
- [ ] Collision: none is shipped (Unity has no collision naming). Add Component → Mesh Collider, Convex on,
      Mesh `<name>_LOD0`: cooks without errors and wraps the model.
- [ ] Textures: Materials tab → Extract Textures; the base colour shows (normal map too, if the version has one).

### Unreal (5.x): `unreal/<name>.fbx`

Content Browser → Import. Static mesh; LOD import on; auto-generated collision off.
- [ ] Scale: height = asset height × 100 uu (1 uu = 1 cm), no import scale needed.
- [ ] Up axis: upright (Z up), not lying on its back.
- [ ] LODs: Static Mesh Editor lists LOD0..LOD3 with triangle counts as above.
- [ ] Collision: Show → Simple Collision shows **one convex hull** around the model (from
      `UCX_<name>_00`), not an auto box. If it is missing, note which name Unreal wanted.
- [ ] Textures: the imported material shows the base colour (normal map too, if the version has one).

### Godot (4.x): `godot/<name>.glb`

Copy the GLB into the project; open the imported scene.
- [ ] Scale: as tall as the asset's height in units (1 unit = 1 m; compare with a 1 m BoxMesh).
- [ ] Up axis: upright (Y up).
- [ ] Collision: a **StaticBody3D** with a CollisionShape3D (ConvexPolygonShape3D) from `<name>-convcolonly`;
      the hull itself is not drawn.
- [ ] LODs: none shipped; Advanced Import Settings → the mesh → Generate LODs is on (Godot's default) and
      the mesh reports LODs.
- [ ] Textures: StandardMaterial3D has albedo, ORM (roughness/metallic) and normal (if the version has one).
