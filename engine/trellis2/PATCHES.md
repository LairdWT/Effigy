# Patches to the stock TRELLIS.2 stack (and Pixal3D, rows 8–12)

`trellis2/` is upstream `microsoft/TRELLIS.2` at `75fbf0183001ed9876c8dbb35de6b68552ee08bd` (MIT, `LICENSE`),
copied **unmodified** (the inference import closure: `models modules pipelines renderers representations
utils`; no `trainers`/`datasets`). Every change is applied at runtime by `patches.prepare()` or at wheel build
time, so re-pulling upstream never loses one. Ideas credited to localmesh-engine (Apache-2.0) are our own code.
